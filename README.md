# 🌿 Biotiflore - Boutique de Produits Cosmétiques

Bienvenue sur **Biotiflore**, une boutique en ligne de produits cosmétiques et de soins de la peau (Skincare).

Ce projet a été réalisé en **HTML, CSS et JavaScript** dans le but de créer une interface moderne, simple et responsive permettant aux utilisateurs de découvrir et d'acheter des produits de beauté.

---

## 📌 Fonctionnalités

- 🏠 Page d'accueil moderne
- 🧴 Catalogue des produits skincare
- 🔍 Barre de recherche
- 📂 Filtrage par catégorie
- ❤️ Produits populaires
- 🛒 Ajout au panier
- 📱 Design Responsive (PC, tablette et mobile)
- 📞 Page Contact
- ℹ️ Page À propos

---

## 🛠️ Technologies utilisées

- HTML5
- CSS3
- JavaScript (Vanilla)
